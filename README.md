# oui

A terminal typing test that tells you **where** you are slow, not just how
fast you are: per-key error rates, the two-key combinations you fumble, the
bigrams that cost you the most time, and a keyboard heatmap of all of it.

Named after the word its author finds hardest to type.

Work in progress — see [`docs/design.md`](docs/design.md) for the plan.
